Merchant Dashboard Reactive Architecture:
Query Invalidation, Root Store Sync & Equilibrium Engineering

A deep-dive engineering playbook cataloging the transition of the Bitnormous Merchant Dashboard into a high-fidelity reactive portal: mounting root actions in layouts, centralizing TanStack cache keys, abstracting invalidations away from UI widgets, and engineering directionless 0% equilibrium micro-UI states.

📌 1. Architectural Overhaul & Core Problems Solved

❌ The Fragmented Legacy Pattern Liabilities
  • Data-fetching hooks (useWalletsAction) mounted in leaf pages; navigating unmounted queries and starved drawers.
  • UI components hardcoded raw string query keys in queryClient.invalidateQueries({ queryKey: [...] }).
  • Dead imperative code like syncToStore callbacks survived alongside declarative useEffect synchronization.
  • Dashboard metric cards were populated with static hardcoded numbers instead of real-time server streams.
  • Metrics with 0% day-over-day change showed directional arrows, signaling false growth or decline.
✅ The Production Standard Hardened
  • Root-Level Mounting in Layout.tsx: Global stores (useFiatBalanceStore, useWalletStore) auto-hydrate once at the layout boundary.
  • Centralized Key Factory (queryKeys.ts): Single source of truth for query scopes and parameter hashes.
  • Dedicated Invalidation Hooks (useInvalidateQueries.ts): UI triggers semantic invalidators (e.g. useInvalidateFiatPayouts()) without touching keys.
  • Real-time useNormalDashboardMetrics: Seamless aggregation of balances, pending queues, conversion rates, and failures.
  • Equilibrium Micro-UI Logic: At 0% diff, arrows are suppressed, color shifts to neutral grey #71717A, and leading signs are stripped.

⚖️ 2. The 0% Equilibrium Paradox & Micro-UI Physics

In quantitative analytics, 0% change is not a positive or negative event—it is metric equilibrium. Rendering directional arrows or biased colors distorts merchant perception.

The Three Rules of Equilibrium State UI

1. Arrow Suppression

When trendNum === 0 || trendDirection === "none", hide both FaArrowUp and FaArrowDown.

2. Neutral Color Palette

Equilibrium must never be tinted green (growth) or red (loss). It renders in muted slate-grey #71717A.

3. Sign Normalization

Strip leading + or - prefixes. Render a clean 0% rather than +0% or -0%.

🏛️ 4. Root-Level Action Mounting Pattern

By lifting the invocation of useWalletsAction() and useFiatBalancesAction() into the top-level Layout.tsx component, data hydration happens once at layout mount and keeps Zustand stores continuously synced across the entire session lifecycle: 

// src/components/Layout.tsx
export const Layout = () => {
  // Mount actions globally at the root layout boundary:
  useFiatBalancesAction();
  useWalletsAction();

  return (
    <div className="flex h-screen overflow-hidden">
      <Sidebar />
      <div className="flex flex-1 flex-col">
        <Header />
        <Outlet />
      </div>
    </div>
  );
};
