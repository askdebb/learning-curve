📐 Mathematical Modeling & Velocity Rules (In Plain English)

To ensure clarity for developers, accounting teams, and auditors, all velocity and health formulas are documented in plain English without cryptic syntax or Greek notation.

1. Week-over-Week Request Velocity Formula
Difference Percentage = ((This Week Total Requests - Previous Week Total Requests) / Previous Week Total Requests) * 100

Plain English Rule: If the difference percentage is exactly 0%, it represents equilibrium. The user interface renders a neutral grey tone (#71717A) with zero arrows. If previous week was 0 but this week has requests, velocity is reported as +100% growth.

2. Webhook Event Delivery Failure Rate
Failure Rate Percentage = (Failed Events Count / Total Deliveries Count) * 100

Plain English Rule: If zero events have failed, the card displays 0% fail rate in neutral grey equilibrium. If even a single event fails, the tone immediately shifts to alert red (#FF3B30) to alert the developer to check endpoint logs.

3. Active vs. Failing Endpoint Health Status
Health Indicator = If Failing Endpoints > 0 Then "X failing" (Red) Else "Y live" (Green)

Plain English Rule: A developer must know at a glance if their webhook endpoints are operational. If any endpoint exhibits consecutive delivery failures, the metric card prominently highlights the number of failing endpoints.

💻 Clean Architecture & Code Snippets

The implementation separates data ingestion, business math, and UI rendering into dedicated modules:

src/hooks/useDeveloperDashboardMetrics.ts TypeScript 
export const useDeveloperDashboardMetrics = () => {
  const { business, isLoading: isBusinessLoading } = useCurrentBusiness();
  const { data: overview, isLoading: isOverviewLoading } = useOverview(business?.id, 30);
  const isLoading = isBusinessLoading || isOverviewLoading;

  const metrics: DashboardMetric[] = useMemo(() => {
    const pmts = overview?.payments;
    const wh = overview?.webhooks;
    const daily = pmts?.daily ?? [];

    // 1. Total Requests Week-over-Week velocity
    const totalRequests = pmts?.total ?? 0;
    const thisWeekTotal = daily.slice(-7).reduce((acc, d) => acc + (d.total || 0), 0);
    const prevWeekTotal = daily.slice(-14, -7).reduce((acc, d) => acc + (d.total || 0), 0);
    const totalDiffPct = prevWeekTotal > 0
      ? Math.round(((thisWeekTotal - prevWeekTotal) / prevWeekTotal) * 100)
      : thisWeekTotal > 0 ? 100 : 0;
    
    // Directionless 0% equilibrium
    const totalTrend = totalDiffPct === 0 ? "0%" : `${totalDiffPct > 0 ? "+" : ""}${totalDiffPct}%`;
    const totalTrendDir: "up" | "down" | "none" = totalDiffPct === 0 ? "none" : totalDiffPct > 0 ? "up" : "down";

    // 2. Success Requests
    const successRequests = pmts?.completed ?? 0;
    // ...
    return [
      { id: "total-requests", label: "Total Requests", value: totalRequests.toLocaleString(), trend: totalTrend, trendDirection: totalTrendDir, tone: totalTrendDir === "down" ? "red" : "green", isLoading },
      { id: "success-requests", label: "Success Requests", value: successRequests.toLocaleString(), ... },
      { id: "events-delivered", label: "Events Delivered", value: (wh?.deliveries ?? 0).toLocaleString(), ... },
      { id: "active-endpoints", label: "Active Endpoints", value: String(wh?.active_endpoints ?? 0), ... }
    ];
  }, [overview, isLoading]);

  return { metrics, overview, business, isLoading };
};
