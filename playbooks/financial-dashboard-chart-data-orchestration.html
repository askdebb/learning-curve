🎯 1. The Architectural Challenge

Financial dashboards must show operational history without lag or data distortion. Key challenges solved in this orchestrator:

  • Moving Beyond Mock Series: Real financial ledgers record single transactions (e.g. $10, $500), not pre-baked monthly totals.
  • Responsive Axis Calculation: Avoid clipping high revenue bars or collapsing low revenue bars by automatically determining dynamic ticks.
  • Zero Layout Shift (CLS): Matching skeleton loaders prevent jumps while queries are resolving in the background.

📐 2. Responsive Axis Scaling Math

const calculateAxisTicks = (maxVal: number) => {
  if (maxVal <= 0) return { yAxisMax: 1000, ticks: [0, 250, 500, 750, 1000] };
  
  const magnitude = Math.pow(10, Math.floor(Math.log10(maxVal)));
  const normalized = maxVal / magnitude;
  let factor = normalized > 5 ? 1.2 : normalized > 2 ? 1.3 : 1.5;

  const targetMax = Math.ceil((maxVal * factor) / (magnitude / 2)) * (magnitude / 2);
  const yAxisMax = Math.max(targetMax, 100);
  const tickStep = yAxisMax / 3;

  return {
    yAxisMax,
    ticks: [0, Math.round(tickStep), Math.round(tickStep * 2), Math.round(yAxisMax)]
  };
};
