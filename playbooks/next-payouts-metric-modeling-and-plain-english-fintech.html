🎯 1. The FinTech Metric Problem

In high-volume crypto and fiat payment gateways, metric cards cannot merely present static or arbitrary counts. Merchants look at the Next payouts card to make critical treasury decisions:

  • Primary Question: "How much capital is currently in-transit to my bank or Mobile Money account?"
  • Secondary Question: "Is my payout velocity increasing or decreasing compared to my last batch?"

Previously, the UI displayed raw counts like "2 pending". The Figma design specified a financial percentage trend (e.g. +56% ↑), requiring us to engineer a relative velocity calculation against completed history.

🔄 2. The On-Demand FinTech Payout Lifecycle

Unlike scheduled corporate payrolls running on monthly cron expressions, Bitnormous merchant payouts are on-demand via POST /fiat/payouts. The lifecycle states are strictly separated:

Lifecycle Status Physical State Counted in "Next Payouts"? Reasoning
pending Queued in gateway database YES Deducted from balance; waiting to dispatch.
processing In-flight via banking/MoMo rails YES Actively transferring across partner rails.
settled Completed & landed in account NO (Historical Baseline) Funds have arrived; used to calculate velocity trend.
failed Rejected by rails NO Reversed back to merchant withdrawable balance.

📖 3. Human-Readable FinTech Formulas vs. LaTeX

We explicitly deprecate academic LaTeX notation in engineering and merchant documents. Plain English descriptions paired with real-world examples remove friction across engineering and product teams.

Next Payouts Amount = Total sum of all pending or processing payout amounts in the active currency.
Example: If you have a GHS 200 processing payout and a GHS 290 pending payout, the card displays GHS 490.00.
Trend % = ((Current Pending Volume − Previous Settled Volume) ÷ Previous Settled Volume) × 100
Example: If your last payout was GHS 300 and your current pending batch is GHS 468, growth is ((468 − 300) ÷ 300) × 100 = +56% (Displays +56% ↑ in green).
Scenario Calculation Display Output Styling Standard
Accelerated Volume ((468 - 300) / 300) * 100 +56% ↑ Green tone with upward arrow
Decelerated Volume ((350 - 500) / 500) * 100 -30% ↓ Red tone with downward arrow
Equilibrium (0% Diff) ((300 - 300) / 300) * 100 0% Neutral grey, NO directional arrow
First Payout (No History) Baseline unavailable 0% Neutral grey, NO directional arrow

💱 4. Multi-Currency Isolation Standard

Bitnormous accounts support multi-currency fiat ledgers (GHS, NGN, USD, KES). Summing amounts across differing currencies produces immediate accounting errors.

We strictly scope the payout query to useFiatPayoutsAction({ currency: activeCurrency }) so that only payouts matching the dashboard's active currency are retrieved and aggregated.

💻 5. Production Implementation in useNormalDashboardMetrics.ts

// src/hooks/useNormalDashboardMetrics.ts
export const useNormalDashboardMetrics = () => {
  const activeCurrency = useFiatBalanceStore((state) => state.activeCurrency);

  // 1. Currency-scoped query: isolates active currency payouts
  const { payouts, isLoading: isPayoutsLoading } = useFiatPayoutsAction({
    currency: activeCurrency,
  });

  // 2. Next payouts: Pending pipeline total and relative percentage trend
  const { pendingPayoutTotal, nextPayoutsTrend, nextPayoutsTrendDir, nextPayoutsTone } = useMemo(() => {
    const pending = payouts.filter((p) => p.status === "pending" || p.status === "processing");
    const settled = payouts.filter((p) => p.status === "settled");

    const total = pending.reduce((sum, p) => sum + (parseFloat(p.amount) || 0), 0);
    const formattedTotal = formatFiatAmount(total.toFixed(2), activeCurrency);

    // Equilibrium fallback if no pending volume or no settled history
    if (total === 0 || settled.length === 0) {
      return {
        pendingPayoutTotal: formattedTotal,
        nextPayoutsTrend: "0%",
        nextPayoutsTrendDir: "none" as const,
        nextPayoutsTone: "green" as const,
      };
    }

    const prevAmount = parseFloat(settled[0].amount) || 0;
    if (prevAmount === 0) {
      return {
        pendingPayoutTotal: formattedTotal,
        nextPayoutsTrend: "+100%",
        nextPayoutsTrendDir: "up" as const,
        nextPayoutsTone: "green" as const,
      };
    }

    const diffPct = Math.round(((total - prevAmount) / prevAmount) * 100);
    if (diffPct === 0) {
      return {
        pendingPayoutTotal: formattedTotal,
        nextPayoutsTrend: "0%",
        nextPayoutsTrendDir: "none" as const,
        nextPayoutsTone: "green" as const,
      };
    }

    return {
      pendingPayoutTotal: formattedTotal,
      nextPayoutsTrend: `${diffPct > 0 ? "+" : ""}${diffPct}%`,
      nextPayoutsTrendDir: diffPct > 0 ? ("up" as const) : ("down" as const),
      nextPayoutsTone: diffPct >= 0 ? ("green" as const) : ("red" as const),
    };
  }, [payouts, activeCurrency]);

  return { metrics };
};
